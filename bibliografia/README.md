La regla del repositorio es priorizar **fuentes primarias, estándares y documentación técnica oficial**. Las notas de clase sirven como punto de partida; las afirmaciones importantes deben contrastarse con referencias externas.

## Lectura transversal

Durante el curso conviene clasificar las fuentes en tres niveles:

1. **Normativa / estándar / framework**: define vocabulario, controles o gestión de riesgo.
2. **Investigación**: papers, benchmarks, ataques o defensas evaluadas experimentalmente.
3. **Implementación**: documentación de proveedores, librerías y herramientas concretas.

## Ficha mínima para incorporar una fuente

```text
Título:
Autor/organización:
Año / versión:
URL / DOI:
Tipo de fuente:
Tema:
Idea principal:
Qué evidencia aporta:
Limitaciones:
Dónde se usa en el repositorio:
```

> Cuando una fuente tenga versiones periódicas, debe consultarse la versión vigente antes de citar requisitos, categorías o controles específicos.
