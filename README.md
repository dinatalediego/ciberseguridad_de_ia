# Ciberseguridad de IA

Repositorio académico para estudiar **ciberseguridad aplicada a sistemas de inteligencia artificial**, con énfasis en fundamentos, modelado de amenazas, controles, experimentación reproducible y análisis de riesgos en sistemas de datos/ML/LLM.

Este repositorio forma parte de mi ruta de aprendizaje de **Maestría en Data Science** y busca convertir apuntes de clase en conocimiento técnico reutilizable: conceptos → modelos de amenaza → laboratorios → evidencia → conclusiones.
